# 위도와 경도 및 공개 고도 자료를 이용한 3D 지구

저장소: https://github.com/gusrms1127/grahpic-earth

## 실행 방법

압축 파일을 받았다면 먼저 압축을 해제한 뒤 `index.html`을 Chrome 또는 Edge에서 엽니다. 서버나 npm 설치는 필요 없습니다. `index.html`, `earth.js`, `data/height-data.js`의 상대 위치를 유지해야 합니다. 실행 중에는 인터넷 연결이 필요하지 않습니다. WebGL을 사용할 수 있는 브라우저가 필요합니다.

## 기능

- 위도와 경도 2도 간격의 구 격자와 32,040개의 삼각형
- NASA 공개 고도 이미지에서 추출한 높이를 이용한 실제 정점 이동
- 고도에 따른 색상과 면별 법선을 이용한 방향광 및 주변광
- Y축 자전과 회전 정지 및 시작
- 회전 속도와 고도 과장 배율 및 빛 방향 조절
- 초기화와 화면 비율 대응

## 파일 구성

| 파일 | 역할 |
| --- | --- |
| index.html | 화면과 정점 셰이더 및 단편 셰이더 |
| earth.js | 좌표 변환과 고도 보간 및 지형 생성과 회전 및 조명 제어 |
| data/height-data.js | 공개 이미지를 1도 간격으로 변환한 고도 밝기 배열 |

## 고도 적용 원리

위도와 경도로 높이 배열의 위치를 찾고 인접한 네 표본을 보간합니다. 밝기 0~255를 NASA 배포 페이지의 0~6400m 범위로 근사 환산합니다. 지구의 기본 반지름을 1로 두고 `1 + 고도(m) / 6371000 * 과장배율`로 정점의 반지름을 계산합니다.

고도 과장 배율은 기본 40배이고 0~100배로 바꿀 수 있습니다. 0배에서는 구형으로 돌아갑니다. 지구를 멈춘 상태에서도 빛 방향을 바꿀 수 있습니다.

## 데이터와 표현의 한계

8bit JPEG를 이용한 시각화용 고도이며 정밀 DEM의 원래 높이를 복원한 것은 아닙니다. 6400m를 넘는 고도와 작은 지형을 정확하게 나타내지 못합니다. 원본을 1도 간격으로 표본화하며 지구 격자는 2도 간격이므로 원본 해상도가 그대로 화면에 나타나지 않습니다. 15m 미만을 바다 색으로 처리하여 해수면 부근 육지나 해안의 색상 분류가 부정확할 수 있습니다. 해저 지형과 실제 자전축 기울기 및 지구 공전은 구현하지 않았습니다.

## 검증 상태

JavaScript 구문 검사와 실제 지형 계산 함수의 수치 검증을 수행했습니다. 삼각형 수와 유한한 좌표 및 단위 법선과 바깥 방향 및 경도 이음매와 고도 0의 반지름을 확인했습니다. 브라우저에서 WebGL 셰이더가 컴파일되는지와 출력 및 버튼 동작까지 확인하지는 못했습니다. 최종 제출 전에 본인 컴퓨터에서 실행하고 그 결과 화면을 보고서에 추가해야 합니다.

## 선택적 고도 배열 재생성

기본 실행에는 Python이 필요하지 않습니다. 원본에서 배열을 다시 생성할 때만 Python과 Pillow를 설치한 뒤 다음을 실행합니다.

```bash
python -m pip install Pillow
python prepare_height.py
```

## AI 사용 내역
